## 게임 소개

플레이어는 오브젝트의 시간을 **가속(미래)** 하거나 **회귀(과거)** 시키는 능력을 사용해 퍼즐을 풀어나갑니다.
시간을 조작할수록 플레이어 캐릭터의 나이가 변화하며, 아이·청년·노인 각 형태마다 서로 다른 능력을 가집니다.
나이 변화와 퍼즐 해결이 맞물리는 것이 핵심 게임플레이입니다.

## 조작법

| 입력 | 행동 |
|------|------|
| A / D | 좌우 이동 |
| Space | 점프 |
| E | 가속 모드 전환 |
| Q | 회귀 모드 전환 |
| 마우스 좌클릭 | 오브젝트 시간 조작 (가속/회귀 모드에서) |

---

## 핵심 컨텐츠

- **시간 모드(가속/회귀)** : 슬로우 모션 진입 후 오브젝트를 클릭해 시간을 가속하거나 되돌림.
- **나이 변화(아이/청년/노인)** : 시간 조작에 따라 플레이어 나이 변화. 능력치가 달라 퍼즐을 푸는 기믹이 됨.
- **세이브 포인트** : 스테이지 클리어 시 자동 저장. 사망 시 가장 최근 세이브 포인트 또는 체크포인트에서 재시작
- **타임라인 기반 컷** : Unity Timeline을 활용한 스테이지 인트로 및 이벤트 연출. 특정 구역 진입 시 자동 재생
